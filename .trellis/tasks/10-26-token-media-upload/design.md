# 技术方案

变更位于 config.go、app.go、新增 Token/API 实现及测试。复用 upload.go 的校验与存储函数，保留旧接口。更新 .env.example、README 与后端契约。

配置从现有环境配置加载链读取 NEWAPI_MEDIA_UPLOAD_TOKENS，生产由 systemd EnvironmentFile 注入；本地明确 source .env，不引入额外配置解析器。逗号分隔令牌，去除空白，拒绝空项及少于32字符令牌；空配置禁用新接口。复用常量时间比较。

先逐文件校验 multipart（单文件最多1项，批量最多9项），在上传目录内的私有暂存目录保存；完整校验成功后使用硬链接发布，避免覆盖文件。逐文件处理限制内存占用。全部发布后返回201。单文件返回 url，批量返回有序 items，每项含 url。失败按400/413/415/500返回；失败清理本次保存文件。禁止记录真实令牌。

使用 httptest 验证配置、鉴权、错误分类、失败无写盘、公开读取及旧接口。回滚二进制或清空配置禁用新功能。

用户已授权部署到 ecs2：使用现有 systemd 配置文件，保留既有令牌并加入本地令牌，备份配置与 current 目标后切换独立发布目录。检查 Nginx 实际请求体限制，必要时备份并调整以匹配媒体限制；通过 nginx -t 后 reload。公网验证并清理测试文件，失败回滚。
