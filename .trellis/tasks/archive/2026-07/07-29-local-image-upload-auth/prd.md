# 实现登录上传与本地图片托管

## Goal

快速交付一个可运行的图床 MVP：只有登录用户能够进入上传页面并上传图片，生成的图片链接无需登录即可直接访问。

## Background

- 当前仓库只有 Trellis 工程配置，没有应用代码。
- 图片存储在本机文件系统，不接入 OSS 或其他对象存储。
- 用户优先要求快速实现，不要求复杂的图床管理能力。
- 目标服务器为 SSH 别名 `ecs2` 对应的 Alibaba Cloud Linux 3 x86_64 主机，最终使用 `image.zhangjianyong.top` 替换该域名现有的“ChatGPT 图片生成操作台”。

## Requirements

- 提供仅密码登录和退出登录能力，不设置用户名；未登录用户不能访问上传页面或上传接口。
- 上传密码由环境变量配置，仓库中不保存可用密码。
- 提供图片选择与上传界面；上传成功后在页面展示完整公开图片链接和复制按钮，并反馈复制结果。
- 服务端同时校验文件声明类型和文件头，只接受 JPEG、PNG、GIF、WebP，单个文件上限为 10 MiB。
- 上传文件使用服务端生成的唯一文件名保存到本地，不能信任客户端文件名作为存储路径。
- 公开图片地址不要求登录，可以直接在浏览器或外部页面中访问。
- 本地上传目录不纳入版本控制，应用重启后已上传图片仍然存在。
- 提供最少的启动、密码和会话密钥配置说明。
- 使用 Go 实现单体服务，由独立 systemd 服务守护并只监听服务器回环地址。
- 使用服务器现有 Nginx 反向代理和 Let’s Encrypt 证书提供 `https://image.zhangjianyong.top` 访问。
- 将 `image.zhangjianyong.top` 纳入服务器现有 SSL 自动续期清单，并验证续期机制可处理该域名。
- 部署切换不得停止共享的 `web-projects-hub-backend.service`，并保留原 Nginx 配置和静态前端以便快速回滚。

## Acceptance Criteria

- [x] 未登录访问上传页面时会进入登录流程。
- [x] 错误密码不能登录，正确密码可以登录并退出；页面不要求输入用户名。
- [x] 登录后可以上传合法图片；页面展示完整公开访问链接，点击复制按钮可写入剪贴板并显示成功反馈。
- [x] 未登录状态可以直接访问已上传图片链接。
- [x] 非图片文件、超出大小限制的文件和无文件请求会返回清晰错误，且不会写入上传目录。
- [x] 上传文件名不可造成目录穿越或覆盖已有文件。
- [x] 重新启动服务后，先前上传图片的公开链接仍然有效。
- [x] 项目提供可复现的本地启动方式，并通过自动化测试覆盖登录保护、上传校验和公开访问主流程。
- [x] Go 服务通过 `image-host.service` 在 `127.0.0.1:18090` 运行，服务器重启后自动启动。
- [x] `http://image.zhangjianyong.top` 跳转 HTTPS，HTTPS 页面、登录、上传和公开图片链接均可正常访问。
- [x] Nginx 配置测试通过，上传大小在 Nginx 和应用两层均受限制，代理传递原始主机名、客户端地址和协议。
- [x] `image.zhangjianyong.top` 已加入现有续期清单，当前证书完成续期或通过针对该域名的续期验证。
- [x] 切换后其他引用共享旧后端的域名不受影响，恢复备份 Nginx 配置即可回退旧页面。

## Technical Notes

- 采用 Go 1.22+ 标准库构建单体服务，前端使用原生 HTML、CSS、JavaScript 并嵌入二进制，不增加数据库或前端构建流程。
- 登录状态使用由 HMAC 签名且带有效期的 `HttpOnly`、`Secure`、`SameSite=Strict` Cookie；服务重启不要求清空登录态，退出登录通过清除 Cookie 完成。
- 本地开发图片保存在 `uploads/`；服务器图片保存在持久化目录 `/var/lib/image-host/uploads`，不随版本发布被替换。
- 服务器没有 Go 工具链；部署使用本机交叉编译的 Linux amd64 静态二进制。
- 当前域名证书将于 2026-08-12 到期，已有 ACME webroot 配置，但域名遗漏在 `/root/ssl_auto_renew/domains.conf` 中。

## Out of Scope

- 用户注册、找回密码、第三方登录和多角色权限。
- 图片列表、删除、编辑、相册和后台管理。
- OSS、CDN、数据库和分布式部署。
- 图片压缩、裁剪、格式转换和内容审核。
- SVG 上传（避免浏览器执行其中的脚本内容）。
- 删除服务器上被替换的旧应用文件，或停用被其他域名共享的旧后端服务。
