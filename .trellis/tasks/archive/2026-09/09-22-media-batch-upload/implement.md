# 实施计划

1. 更新后端上传类型、大小限制、媒体内容校验和安全存储名称白名单。
2. 将单文件 multipart 解析改为最多 9 个文件的逐项解析，输出统一 `results` 响应。
3. 调整请求体限制、错误映射和公开文件响应头。
4. 更新前端多选/拖放、文件列表、总体进度、逐项结果和复制链接交互。
5. 增补后端认证、批量部分成功、数量上限、音视频合法/非法内容和公开访问测试。
6. 增补前端静态资源与协议示例检查，并更新 README 的支持类型和迁移说明。
7. 运行 `gofmt`、`go test ./...`，再执行完整质量检查。

## 风险检查点

- 批量请求体必须覆盖 9 个 200 MiB 视频及 multipart 开销，但不能移除单文件限制。
- 文件级失败不能留下半写入文件。
- 任何未认证批量请求都必须在解析文件前返回 401。
- `results` 顺序应与请求文件顺序一致，便于旧客户端迁移。
